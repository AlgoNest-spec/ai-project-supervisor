# Security policy

This project contains general workflow guidance and synthetic examples. Do not submit credentials, personal data, confidential project files, or proprietary agent prompts in issues or pull requests.

Report suspected security or privacy problems privately to the repository maintainer. Do not include sensitive values in a public issue. If a credential was exposed, revoke or rotate it; deleting the visible file alone does not remove it from Git history.

The skill does not grant agent-dispatch capabilities or authorize external side effects. Review the tools and permissions supplied by the host platform before using delegated agents.
